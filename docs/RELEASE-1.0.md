## O que está incluído

### Desktop
- KDE Plasma com tema Katu
- SDDM com tela de login personalizada
- Plymouth — splash de boot animado
- GRUB com menu Katu

### Aplicativos
- Firefox ESR — navegador web
- LibreOffice — suíte de escritório
- VLC — reprodutor multimídia
- Dolphin — gerenciador de arquivos
- Konsole — terminal
- Ark — compactação
- Okular — leitor PDF
- KDE Connect — conectar smartphone

### Sistema
- Katu Welcome — app de boas-vindas
- Calamares — instalador gráfico
- Discover — loja de aplicativos
- NetworkManager — gerenciamento de rede
- Flatpak (suporte, Flathub opcional)
