## Firmware non-free

O Katu OS inclui firmware de dispositivos (non-free) do Debian.

Estes firmwares possuem licenças proprietárias dos fabricantes.

A redistribuição é permitida conforme os termos Debian non-free.

---

## Créditos obrigatórios preservados

Katu OS **não remove** créditos upstream de nenhum componente.

O arquivo `/usr/share/doc/<pacote>/copyright` de cada pacote é preservado integralmente.
